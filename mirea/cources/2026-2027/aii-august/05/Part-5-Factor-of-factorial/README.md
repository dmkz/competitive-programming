## Глава 5. Степень вхождения простого числа в факториал

В конце прошлой главы мы задались интересным вопросом: как факторизовать число, если оно задано в виде факториала? 

Напомним, что факториал числа $n$ (обозначается как $n!$) — это произведение всех натуральных чисел от $1$ до $n$. Факториалы растут с пугающей скоростью. Например, $20!$ уже не помещается в 64-битный тип данных, а $100!$ состоит из 158 цифр. Вычислить такое число напрямую, а затем применить к нему алгоритмы из предыдущих глав, абсолютно невозможно.

Однако в олимпиадных задачах часто требуется узнать, **сколько раз $n!$ делится на заданное простое число $p$**. Иными словами, нужно найти степень вхождения числа $p$ в разложение $n!$ на простые множители. Для решения этой задачи существует элегантная формула, известная как **формула Лежандра**.

## 5.1. Вывод формулы Лежандра

Давайте рассуждать логически. Факториал — это произведение:
$$n! = 1 \cdot 2 \cdot 3 \cdot \ldots \cdot n$$

Каждое число в этом ряду, которое кратно $p$, даёт в итоговое произведение как минимум один множитель $p$. Сколько всего таких чисел на отрезке от $1$ до $n$? Очевидно, их ровно $\lfloor \frac{n}{p} \rfloor$ (здесь скобки означают округление вниз, то есть целочисленное деление).

Например, если $n = 100$ и $p = 2$, то чётных чисел от $1$ до $100$ ровно $50$. Значит, мы уже нашли $50$ двоек.

Но подождите! Некоторые числа делятся не просто на $p$, а на $p^2$ (например, $4, 8, 12$ делятся на $2^2 = 4$). Каждое такое число содержит внутри себя *две* двойки. Одну из них мы уже посчитали на предыдущем шаге. Значит, за каждое число, кратное $p^2$, нужно добавить к ответу ещё по одной двойке. Сколько таких чисел? Ровно $\lfloor \frac{n}{p^2} \rfloor$.

Продолжая эту логику, числа, кратные $p^3$, содержат по три множителя $p$. Два из них мы уже учли (когда считали кратные $p$ и кратные $p^2$), поэтому остаётся добавить их ещё по одному разу. Их количество равно $\lfloor \frac{n}{p^3} \rfloor$.

Этот процесс продолжается до тех пор, пока степень $p^k$ не превысит $n$. В итоге мы получаем красивую сумму:
$$\text{Степень } p \text{ в } n! = \left\lfloor \frac{n}{p} \right\rfloor + \left\lfloor \frac{n}{p^2} \right\rfloor + \left\lfloor \frac{n}{p^3} \right\rfloor + \ldots$$

## 5.2. Оптимизация вычислений в коде

Прямолинейная реализация этой формулы подразумевает возведение числа $p$ в степень $k$ на каждом шаге. Но в олимпиадном программировании это опасный путь: если $n$ достигает $10^{18}$, то очередная степень $p^k$ может переполниться и пробить потолок 64-битного типа данных.

К счастью, математика подсказывает нам гениальный трюк. Заметим, что $\lfloor \frac{n}{p^2} \rfloor$ — это то же самое, что $\lfloor \frac{\lfloor n/p \rfloor}{p} \rfloor$. 
То есть, вместо того чтобы увеличивать знаменатель, мы можем на каждом шаге **просто делить само число $n$ на $p$**! 

Алгоритм становится невероятно простым:
1. Делим $n$ на $p$.
2. Прибавляем результат к ответу.
3. Повторяем, пока $n > 0$.

Асимптотика такого решения составляет $O(\log_p n)$, что работает за считанные микросекунды даже для астрономически больших чисел.

<details>
<summary><strong>C++: степень вхождения в факториал</strong></summary>

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int64_t n, p; cin >> n >> p;
    int64_t answ = 0;
    
    // На каждом шаге n превращается в n / p
    while (n > 0) {
        answ += n / p;
        n /= p;
    }
    
    cout << answ << endl;
}

main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int tt; cin >> tt;
    while (tt --> 0) solve();
}
```

</details>

<details>
<summary><strong>Python3: степень вхождения в факториал</strong></summary>

```python
tt = int(input())
for _ in range(tt):
    n, p = map(int, input().split())
    answ = 0
    
    # На каждом шаге n превращается в n // p
    while n > 0:
        answ += n // p
        n //= p
        
    print(answ)
```

</details>

<details>
<summary><strong>Пример запуска</strong></summary>

```text
Ввод
1
100 2

Вывод
97
```
Давайте проверим вручную: 
$100 / 2 = 50$
$50 / 2 = 25$
$25 / 2 = 12$
$12 / 2 = 6$
$6 / 2 = 3$
$3 / 2 = 1$
Сумма: $50 + 25 + 12 + 6 + 3 + 1 = 97$. 
Это означает, что $100!$ делится на $2^{97}$, но не делится на $2^{98}$.
</details>

> [!NOTE]
> Классическая задача, которая решается этим методом: **«Сколькими нулями оканчивается число $n!$ ?»**
> 
> Ноль на конце числа образуется при умножении на $10$, а $10 = 2 \cdot 5$. Значит, нам нужно найти, сколько пар $(2, 5)$ содержится в разложении $n!$. Поскольку двоек в факториале всегда с избытком (каждое второе число чётное), количество нулей строго равно степени вхождения пятёрки. Достаточно вызвать нашу функцию для $p = 5$.
