## 18. Возрастающая подпоследовательность

Дан массив из $n$ $(1 \le n \le 4000)$ чисел. Нужно найти длину его наибольшей строго возрастающей подпоследовательности. Подпоследовательность сохраняет порядок индексов, но не обязана состоять из соседних элементов. Например, в массиве $[5, 1, 6, 2, 3, 4, 0, 7]$ можно выбрать $[1, 2, 3, 4, 7]$ длины $5$.

## 19. Динамика, которая заканчивается в позиции

> [!NOTE]
> Для подпоследовательности важно различать последний выбранный индекс. Состояние должно знать элемент, с которым будет сравниваться следующий кандидат.

Пусть $\text{dp}_i$ – наибольшая длина строго возрастающей подпоследовательности, которая **заканчивается** элементом $a_i$. Слово «заканчивается» не случайно: оно сразу подсказывает последнее действие. Перед $a_i$ в такой подпоследовательности стоит некоторый элемент $a_j$ с меньшим индексом и меньшим значением.

Для каждого $j<i$ с $a_j<a_i$ можно продолжить лучшую подпоследовательность из состояния $j$:

$$
\text{dp}_i = 1 + \max_{j<i,\ a_j<a_i} \text{dp}_j.
$$

Если подходящего $j$ нет, подпоследовательность состоит только из $a_i$, поэтому база равна $\text{dp}_i=1$. Мы считаем индексы слева направо, и к моменту обработки $i$ известны все допустимые $j$.

> [!IMPORTANT]
> Переход перебирает все индексы, которые могут быть предпоследними в ответе.
>
> Условие $a_j<a_i$ отвечает за строгое возрастание, а условие $j<i$ – за порядок исходного массива.

## 20. Разбор примера

Рассмотрим массив $[5, 1, 6, 2, 3, 4, 0, 7]$. В строке `prev` указан один индекс, который даёт лучшее значение. Прочерк означает, что меньшего подходящего элемента слева нет.

| индекс $i$ | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| $a_i$ | 5 | 1 | 6 | 2 | 3 | 4 | 0 | 7 |
| `prev[i]` | – | – | 0 | 1 | 3 | 4 | – | 5 |
| `dp[i]` | 1 | 1 | 2 | 2 | 3 | 4 | 1 | 5 |

Например, для $i=5$ предшественник равен $4$: $a_4=3<a_5=4$, поэтому `dp[5] = dp[4] + 1 = 4`. Для последнего элемента выбираем $j=5$ и получаем `dp[7] = dp[5] + 1 = 5`. Если идти по этим предкам от $7$, выйдет подпоследовательность с индексами $[1,3,4,5,7]$ и значениями $[1,2,3,4,7]$.

Ответ не обязан находиться в последней позиции массива. Например, в массиве $[1, 2, 3, 0]$ значения `dp` равны $[1, 2, 3, 1]$, а ответ равен $3$. Поэтому после вычисления всех состояний нужно взять максимум по массиву `dp`.

```cpp
vector<int> dp(n, 1);
for (int i = 0; i < n; i++)
	for (int j = 0; j < i; j++)
		if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1);
```

```python
dp = [1] * n
for i in range(n):
	for j in range(i):
		if a[j] < a[i]: dp[i] = max(dp[i], dp[j] + 1)
```

## 21. Цена прямого перехода

Для каждого $i$ мы перебираем все предыдущие $j$. Поэтому число сравнений равно $O(n^2)$, а память – $O(n)$. При $n \le 4000$ это нормальное решение, особенно если после длины нужно восстановить саму подпоследовательность.

Состояние по последнему индексу достаточно, потому что условие продолжения зависит только от $a_i$. Любая следующая позиция $k$ может продолжить подпоследовательность с концом в $i$ тогда и только тогда, когда $i<k$ и $a_i<a_k$. Более ранние элементы этой подпоследовательности уже проверены между собой и не влияют на следующий выбор. Поэтому из всех подпоследовательностей с одним концом нужно хранить только наибольшую длину.
