## Глава 4. Шары, коробки и метод перегородок

В предыдущих главах мы научились вычислять сочетания и применять их для подсчёта путей по сетке. Теперь рассмотрим ещё одну классическую комбинаторную модель — распределение одинаковых объектов по нескольким группам.

Эту модель называют задачей о **шарах и коробках**, а способ её решения — **методом перегородок**. С его помощью можно подсчитывать количество распределений, целочисленных решений уравнений и разложений числа на слагаемые.

## 4.1. Одинаковые шары и различные коробки

Пусть имеется $n$ одинаковых шаров и $k$ различных коробок. Каждый шар нужно положить в одну из коробок, причём коробки могут оставаться пустыми.

Нас интересует только итоговое количество шаров в каждой коробке. Порядок, в котором мы раскладывали шары, значения не имеет.

Например, распределение

$$(2,1,2)$$

означает, что в первой коробке находятся два шара, во второй — один, а в третьей — два.

Коробки считаются различными, поэтому распределения $(2,1,2)$ и $(1,2,2)$ не совпадают: в них разное количество шаров находится в первой и второй коробках.

Представим каждый шар символом `*`, а границы между соседними коробками — символом `|`. Тогда распределение $(2,1,2)$ можно записать так:

```text
**|*|**
```

Первый участок соответствует первой коробке, второй — второй, а третий — третьей.

Чтобы разделить шары между $k$ коробками, требуется $k-1$ перегородка. Вместе с $n$ шарами получается последовательность из $n+k-1$ символов:

- $n$ шаров;
- $k-1$ перегородки.

Достаточно выбрать позиции для перегородок. Остальные позиции автоматически займут шары. Следовательно, количество распределений равно

$$C_{n+k-1}^{k-1}.$$

По симметрии сочетаний можно вместо перегородок выбрать позиции для шаров:

$$C_{n+k-1}^{k-1}=C_{n+k-1}^{n}.$$

Перегородки могут находиться рядом или стоять по краям последовательности. Именно так изображаются пустые коробки. Например,

```text
**||***
```

соответствует распределению $(2,0,3)$, а запись

```text
|**|***
```

— распределению $(0,2,3)$.

Таким образом, метод перегородок сразу учитывает все распределения, в которых коробки могут быть пустыми.

> [!IMPORTANT]
> Формула $C_{n+k-1}^{k-1}$ применяется, когда шары одинаковые, коробки различимы и в каждой коробке может находиться любое неотрицательное количество шаров.

Если шары различимы, задача меняется. Каждый из $n$ шаров независимо выбирает одну из $k$ коробок, поэтому без дополнительных ограничений ответ будет равен $k^n$.

## 4.2. Неотрицательные решения уравнения

Обозначим через $x_i$ количество шаров в $i$-й коробке. Тогда любое распределение соответствует решению уравнения

$$x_1+x_2+\ldots+x_k=n,$$

где все переменные являются целыми и неотрицательными:

$$x_i\ge 0.$$

Например, распределению $(2,0,3)$ соответствует решение $x_1=2$, $x_2=0$, $x_3=3$.

Это соответствие работает в обе стороны:

- распределение шаров однозначно задаёт значения $x_1,x_2,\ldots,x_k$;
- любое неотрицательное целочисленное решение показывает, сколько шаров лежит в каждой коробке.

Поэтому количество неотрицательных целочисленных решений уравнения равно

$$C_{n+k-1}^{k-1}.$$

В условии задачи могут не упоминаться шары и коробки. Если требуется распределить целое количество одинаковых объектов между различимыми группами без верхних ограничений, часто достаточно мысленно перейти к этой модели.

## 4.3. Разложение числа на натуральные слагаемые

Теперь требуется представить число $n$ в виде суммы $k$ натуральных чисел:

$$x_1+x_2+\ldots+x_k=n,\qquad x_i\ge 1.$$

Здесь порядок слагаемых важен. Например, разложения $1+2+4$ и $2+1+4$ считаются различными, поскольку значения $x_1$ и $x_2$ поменялись местами.

Снова представим $n$ единиц одинаковыми шарами, а каждое слагаемое — количеством шаров в соответствующей коробке. Поскольку все слагаемые положительны, пустых коробок быть не должно.

Сначала положим по одному шару в каждую из $k$ коробок. После этого останется $n-k$ шаров, которые уже можно распределять без ограничений.

По формуле из предыдущего раздела количество способов равно

$$C_{(n-k)+k-1}^{k-1}=C_{n-1}^{k-1}.$$

Следовательно, число упорядоченных разложений $n$ на $k$ натуральных слагаемых равно

$$C_{n-1}^{k-1}.$$

Эту формулу можно увидеть и напрямую. Запишем $n$ единиц подряд:

```text
1 1 1 1 1 1 1
```

Между ними находится $n-1$ промежуток. Чтобы получить $k$ непустых групп, нужно выбрать $k-1$ промежуток и поставить в них знаки сложения.

Например, для $n=7$ и $k=3$ можно выбрать такие границы:

```text
1 1 | 1 | 1 1 1 1
```

Они задают разложение

$$7=2+1+4.$$

Каждый выбор двух промежутков даёт ровно одно разложение числа $7$ на три натуральных слагаемых. Всего таких разложений

$$C_6^2=15.$$

Разложение существует только при $1\le k\le n$. Если $k>n$, даже минимальная возможная сумма из $k$ натуральных слагаемых, равная $k$, уже превышает $n$.

## 4.4. Вычисление ответа по модулю

Чтобы найти количество разложений числа $n$ на $k$ натуральных слагаемых, необходимо вычислить сочетание

$$C_{n-1}^{k-1}.$$

При $n<mod$ воспользуемся факториалами и обратными факториалами из второй главы:

$$C_{n-1}^{k-1}=fact[n-1]\cdot invFact[k-1]\cdot invFact[n-k]\bmod mod.$$

Предподсчёт занимает $O(n)$ времени и памяти, а само сочетание после него вычисляется за $O(1)$.

Приведённые программы предполагают, что выполняется условие $1\le k\le n<mod$.

Полные реализации доступны отдельно для самостоятельного изучения: [C++](examples/example-01.cpp) и [Python3](examples/example-01.py).

<details>
<summary><strong>C++: разложение числа на натуральные слагаемые</strong></summary>

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll mod = 1000000007;
ll power(ll a, ll exponent) {
	ll answ = 1;
	while (exponent > 0) {
		if (exponent % 2 == 1) answ = answ * a % mod;
		a = a * a % mod;
		exponent /= 2;
	}
	return answ;
}
main() {
	int n, k; cin >> n >> k;
	// Предподсчитываем факториалы для сочетания C(n - 1, k - 1).
	vector<ll> fact(n + 1), invFact(n + 1);
	fact[0] = 1;
	for (int i = 1; i <= n; i++) fact[i] = fact[i - 1] * i % mod;
	invFact[n] = power(fact[n], mod - 2);
	for (int i = n; i >= 1; i--) invFact[i - 1] = invFact[i] * i % mod;
	// Выбираем k - 1 промежутков между n единицами для знаков сложения.
	cout << fact[n - 1] * invFact[k - 1] % mod * invFact[n - k] % mod << '\n';
}
```

</details>

<details>
<summary><strong>Python3: разложение числа на натуральные слагаемые</strong></summary>

```python
mod = 10 ** 9 + 7
def power(a, exponent):
	answ = 1
	while exponent > 0:
		if exponent % 2 == 1: answ = answ * a % mod
		a = a * a % mod
		exponent //= 2
	return answ
n, k = map(int, input().split())
# Предподсчитываем факториалы для сочетания C(n - 1, k - 1).
fact = [1] * (n + 1)
for i in range(1, n + 1): fact[i] = fact[i - 1] * i % mod
invFact = [1] * (n + 1)
invFact[n] = power(fact[n], mod - 2)
for i in range(n, 0, -1): invFact[i - 1] = invFact[i] * i % mod
# Выбираем k - 1 промежутков между n единицами для знаков сложения.
print(fact[n - 1] * invFact[k - 1] % mod * invFact[n - k] % mod)
```

</details>

<details>
<summary><strong>Пример запуска</strong></summary>

```text
Ввод
7 3

Вывод
15
```

Между семью единицами есть шесть промежутков. Для получения трёх слагаемых нужно выбрать два из них, поэтому ответ равен $C_6^2=15$.

</details>

## 4.5. Как выбрать правильную формулу

Метод перегородок даёт две основные формулы.

| Условие | Интерпретация | Количество решений |
|---|---|---:|
| $x_1+x_2+\ldots+x_k=n$, $x_i\ge 0$ | Коробки могут быть пустыми | $C_{n+k-1}^{k-1}$ |
| $x_1+x_2+\ldots+x_k=n$, $x_i\ge 1$ | В каждой коробке должен быть хотя бы один шар | $C_{n-1}^{k-1}$ |

В первом случае сразу распределяем все $n$ шаров. Во втором сначала кладём по одному шару в каждую коробку, а затем распределяем оставшиеся $n-k$ шаров.

Перед применением формулы необходимо проверить ещё два условия:

- объекты должны быть одинаковыми;
- группы, коробки или переменные должны быть различимыми.

Если коробки неразличимы или количество шаров в коробке ограничено сверху, обычная формула перегородок напрямую не применяется. В задачах с верхними ограничениями часто сначала считают все распределения, а затем исключают недопустимые с помощью формулы включений-исключений.
