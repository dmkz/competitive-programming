## Глава 2. Вычисления по простому модулю

В комбинаторных задачах ответ часто оказывается огромным. Например, уже число $30!$ не помещается в стандартный 64-битный целочисленный тип. При этом в задаче обычно требуется вывести не само число, а только его остаток по некоторому модулю, например по модулю

$$
mod=10^9+7.
$$

Это простое число часто встречается в олимпиадных задачах. Простота модуля особенно важна при делении: она позволит нам находить обратные элементы с помощью малой теоремы Ферма.

В этой главе мы разберём основные операции по модулю, научимся быстро возводить числа в степень, а затем применим полученные инструменты для вычисления сочетаний.

## 2.1. Сразу работаем с остатками

Предположим, что ответ задачи равен некоторому очень большому числу $x$, но вывести требуется только

$$
x\bmod mod.
$$

Не нужно сначала вычислять $x$, а затем брать остаток. Огромное значение может не поместиться в доступные типы данных, даже если его остаток совсем мал.

Вместо этого на каждом шаге будем хранить только остаток — целое число от $0$ до $mod-1$.

Так можно поступать благодаря следующим свойствам:

$(a+b)\bmod mod =\bigl((a\bmod mod)+(b\bmod mod)\bigr)\bmod mod$,

$(a-b)\bmod mod = \bigl((a\bmod mod)-(b\bmod mod)\bigr)\bmod mod$,

$(a\cdot b)\bmod mod = \bigl((a\bmod mod)\cdot(b\bmod mod)\bigr)\bmod mod$.

Иными словами, при сложении, вычитании и умножении можно заменить исходные числа их остатками. Итоговый остаток от этого не изменится.

> [!IMPORTANT]
> Если задача требует вывести количество способов по модулю, выполняйте все вычисления по модулю с самого начала. Не пытайтесь сначала получить обычное значение ответа.

## 2.2. Сложение, вычитание и умножение

Пусть $a$ и $b$ — уже нормализованные остатки, то есть

$$
0\le a,b < mod.
$$

Тогда сложение по модулю выполняется так:

$$
(a+b)\bmod mod.
$$

Умножение выполняется аналогично:

$$
(a\cdot b)\bmod mod.
$$

При вычитании результат может оказаться отрицательным. Поэтому обычно к нему предварительно прибавляют модуль:

$$
(a-b+mod)\bmod mod.
$$

Например, по модулю $7$:

$$
3-5\equiv -2\equiv 5\pmod 7.
$$

Именно поэтому выражение

```cpp
(a - b + mod) % mod
```

даёт остаток $5$, а не отрицательное число.

> [!NOTE]
> Формула с одним прибавлением `mod` предполагает, что `a` и `b` уже находятся в диапазоне от `0` до `mod - 1`.

В C++ необходимо помнить о переполнении при умножении. Даже если оба остатка помещаются в `int`, их произведение может не поместиться. Поэтому перед умножением следует перейти к 64-битному типу:

```cpp
int result = int(int64_t(a) * b % mod);
```

В Python целые числа могут расти практически без ограничений, однако остаток всё равно следует брать после каждой операции. Благодаря этому промежуточные значения не будут становиться неоправданно большими.

## 2.3. Почему нельзя делить обычным способом

Со сложением, вычитанием и умножением всё достаточно просто. С делением возникает новая проблема.

В модульной арифметике нельзя написать

```cpp
a / b % mod
```

и ожидать правильный результат. В C++ оператор `/` выполняет обычное целочисленное деление, а в Python оператор `/` создаёт вещественное число. Ни одна из этих операций не соответствует делению по модулю.

Вместо деления на $b$ нужно умножить на число, которое отменяет умножение на $b$. Такое число называется **обратным элементом**.

Деление по модулю записывается следующим образом:

$$
\frac{a}{b}\equiv a\cdot b^{-1}\pmod{mod}.
$$

Здесь $b^{-1}$ — не обычная дробь $\frac{1}{b}$, а обратный к $b$ элемент по модулю.

## 2.4. Обратный элемент

Число $b^{-1}$ называется обратным к $b$ по модулю $mod$, если

$$
b\cdot b^{-1}\equiv 1\pmod{mod}.
$$

Рассмотрим пример по модулю $7$. Обратным к $3$ является число $5$, потому что

$$
3\cdot 5=15\equiv 1\pmod 7.
$$

Поэтому деление на $3$ по модулю $7$ заменяется умножением на $5$. Например,

$$
\frac{5}{3}
\equiv 5\cdot 3^{-1}
\equiv 5\cdot 5
\equiv 25
\equiv 4
\pmod 7.
$$

Таким образом, задача деления сводится к поиску обратного элемента.

> [!WARNING]
> У нулевого остатка обратного элемента не существует. Нельзя делить на число, которое равно нулю по модулю.

Для простого модуля обратный элемент существует у любого ненулевого остатка. Найти его позволяет малая теорема Ферма.

## 2.5. Малая теорема Ферма

Пусть $mod$ — простое число, а $b$ не делится на $mod$. Тогда малая теорема Ферма утверждает, что

$$
b^{mod-1}\equiv 1\pmod{mod}.
$$

Представим левую часть в виде произведения:

$$
b^{mod-1}=b\cdot b^{mod-2}.
$$

Следовательно,

$$
b\cdot b^{mod-2}\equiv 1\pmod{mod}.
$$

По определению обратного элемента отсюда получаем

$$
b^{-1}\equiv b^{mod-2}\pmod{mod}.
$$

Таким образом, чтобы найти обратный элемент, достаточно вычислить

$$
b^{mod-2}\bmod mod.
$$

Однако показатель $mod-2$ может быть очень большим. Возводить число в степень обычным циклом за $O(mod)$ слишком медленно. Вместо этого используется алгоритм быстрого возведения в степень.

## 2.6. Быстрое возведение в степень

Степень $a^e$ можно вычислить, используя разложение показателя пополам.

Если $e$ чётно, то

$$
a^e=\left(a^{e/2}\right)^2.
$$

Если $e$ нечётно, то

$$
a^e=\left(a^{\lfloor e/2\rfloor}\right)^2\cdot a.
$$

На каждом шаге показатель степени уменьшается примерно в два раза. Поэтому алгоритм работает за $O(\log e)$.

### Рекурсивная реализация

Рекурсивный вариант непосредственно повторяет приведённые формулы.

<details>
<summary><strong>C++</strong></summary>

```cpp
int64_t powerRecursive(int64_t a, int e) {
	if (e == 0) return 1;
	int64_t half = powerRecursive(a, e / 2);
	int64_t answ = half * half % mod;
	if (e % 2 == 1) answ = answ * a % mod;
	return answ;
}
```

</details>

<details>
<summary><strong>Python3</strong></summary>

```python
def power_recursive(a, e):
    if e == 0:
        return 1
    half = power_recursive(a, e // 2)
    answ = half * half % mod
    if e % 2 == 1:
        answ = answ * a % mod
    return answ
```

</details>

Базовый случай соответствует нулевой степени:

$$
a^0=1.
$$

После рекурсивного вычисления $a^{\lfloor e/2\rfloor}$ результат возводится в квадрат. Если показатель был нечётным, результат дополнительно умножается на $a$.

Рассмотрим вызов `powerRecursive(3, 13)` по модулю $10^9+7$. Все промежуточные значения здесь меньше модуля, поэтому остаток не меняет вычисления. Сначала рекурсия уменьшает показатель вдвое:

```text
powerRecursive(3, 13)
powerRecursive(3, 6)
powerRecursive(3, 3)
powerRecursive(3, 1)
powerRecursive(3, 0)
```

Базовый вызов возвращает $1$. Затем рекурсия разворачивается в обратном порядке:

| Показатель $e$ | Значение `half` | Возвращаемое значение |
|---:|---:|---:|
| $1$ | $1$ | $1^2\cdot3=3$ |
| $3$ | $3$ | $3^2\cdot3=27$ |
| $6$ | $27$ | $27^2=729$ |
| $13$ | $729$ | $729^2\cdot3=1594323$ |

Таким образом, `powerRecursive(3, 13)` получает $3^{13}=1594323$, сделав всего четыре рекурсивных шага после базового случая, а не двенадцать последовательных умножений.

### Итеративная реализация

На практике чаще используется итеративный вариант.

Будем хранить:

- в `a` — текущую степень исходного числа;
- в `answ` — уже собранную часть ответа;
- в `e` — ещё не обработанную часть показателя.

Если текущий двоичный разряд показателя равен единице, домножаем ответ на `a`. После этого возводим `a` в квадрат и переходим к следующему разряду показателя.

<details>
<summary><strong>C++</strong></summary>

```cpp
int64_t power(int64_t a, int e) {
	int64_t answ = 1;
	while (e > 0) {
		if (e % 2 == 1) answ = answ * a % mod;
		a = a * a % mod;
		e /= 2;
	}
	return answ;
}
```

</details>

<details>
<summary><strong>Python3</strong></summary>

```python
def power(a, e):
    answ = 1
    while e > 0:
        if e % 2 == 1:
            answ = answ * a % mod
        a = a * a % mod
        e //= 2
    return answ
```

</details>

Теперь обратный к ненулевому числу $b$ по простому модулю можно найти так:

```cpp
power(b, mod - 2)
```

В Python реализацию быстрого возведения обычно не пишут вручную. Встроенная функция `pow` сразу умеет работать по модулю:

```python
inverse = pow(b, -1, mod)
value = pow(a, e, mod)
```

Первый вызов находит обратный к $b$ элемент, а второй вычисляет $a^e\bmod mod$. Как и раньше, обратный элемент существует только при взаимной простоте $b$ и $mod$. В частности, для простого `mod` нельзя передавать нулевой остаток `b`.

Таким образом, мы умеем выполнять по модулю все необходимые операции:

- складывать;
- вычитать;
- умножать;
- возводить в степень;
- делить на ненулевой остаток.

Осталось применить эти операции к вычислению сочетаний.

## 2.7. Сочетания с помощью динамики

Сочетание из $n$ элементов по $k$ обозначается как $\binom{n}{k}$ или, в другой распространённой записи, $C_n^k$.

Самый наглядный способ вычислять сочетания — вспомнить задачу о черепашке, которая движется по прямоугольной таблице.

Пусть из клетки $(0,0)$ нужно сделать:

- $n$ шагов вниз;
- $k$ шагов вправо.

Обозначим через $ways[i][j]$ количество путей, в которых уже сделано $i$ шагов вниз и $j$ шагов вправо.

В клетку $(i,j)$ можно прийти двумя способами:

- сверху, из клетки $(i-1,j)$;
- слева, из клетки $(i,j-1)$.

Поэтому

$$
ways[i][j]=ways[i-1][j]+ways[i][j-1].
$$

Все вычисления выполняются по модулю.

На границе таблицы путь единственный, поэтому

$$
ways[i][0]=1,
$$

$$
ways[0][j]=1.
$$

Теперь свяжем число путей с сочетаниями. В каждом маршруте делается ровно $n+k$ шагов. Чтобы однозначно задать маршрут, достаточно выбрать $k$ позиций, на которых будут сделаны шаги вправо. Поэтому

$$
ways[n][k]=\binom{n+k}{k}.
$$

Следовательно, если таблица обозначена как $C$, то значение `C[n][k]` соответствует сочетанию

$$
\binom{n+k}{k}.
$$

Алгоритм работает за $O(nk)$ времени и использует $O(nk)$ памяти.

Этот способ удобен при небольших ограничениях, особенно если в процессе решения нужны значения для многих соседних пар.

Полные реализации:

- [C++](examples/example-01.cpp);
- [Python3](examples/example-01.py).

<details>
<summary><strong>C++: динамика для сочетания</strong></summary>

```cpp
#include <bits/stdc++.h>
using namespace std;
const int mod = 1000000007;
main() {
    int n, k; cin >> n >> k;
    // ways[i][j] хранит число путей после i шагов вниз и j шагов вправо.
    vector<vector<int>> ways(n + 1, vector<int>(k + 1));
    ways[0][0] = 1;
    // В каждую клетку приходим из клетки сверху или слева.
    for (int i = 0; i <= n; i++)
        for (int j = 0; j <= k; j++) {
            if (i == 0 && j == 0) continue;
            int fromTop = i == 0 ? 0 : ways[i - 1][j];
            int fromLeft = j == 0 ? 0 : ways[i][j - 1];
            ways[i][j] = (fromTop + fromLeft) % mod;
        }
    cout << ways[n][k] << '\n';
}
```

</details>

<details>
<summary><strong>Python3: динамика для сочетания</strong></summary>

```python
mod = 10 ** 9 + 7
n, k = map(int, input().split())
# ways[i][j] хранит число путей после i шагов вниз и j шагов вправо.
ways = [[0] * (k + 1) for i in range(n + 1)]
ways[0][0] = 1
# В каждую клетку приходим из клетки сверху или слева.
for i in range(n + 1):
    for j in range(k + 1):
        if i == 0 and j == 0: continue
        fromTop = 0 if i == 0 else ways[i - 1][j]
        fromLeft = 0 if j == 0 else ways[i][j - 1]
        ways[i][j] = (fromTop + fromLeft) % mod
print(ways[n][k])
```

</details>

<details>
<summary><strong>Пример запуска</strong></summary>

```text

Вывод

```

Здесь нужно сделать два шага вниз и три шага вправо. Всего получается пять шагов, из которых выбираются три позиции для шагов вправо:

$C_5^3=10$.

</details>

## 2.8. Одно сочетание при небольшом $k$

Предыдущий способ строит целую таблицу. Если требуется вычислить только одно сочетание, а $k$ мало, можно воспользоваться формулой напрямую.

Сначала применим симметрию сочетаний:

$$
\binom{n}{k}=\binom{n}{n-k}.
$$

Поэтому достаточно взять $limit=\min(k,n-k)$.

После этого формулу сочетания можно записать так:

$$
\binom{n}{k}
=
\frac{n(n-1)\cdots(n-limit+1)}
{1\cdot 2\cdots limit}.
$$

В цикле для каждого $i$ от $1$ до $limit$ выполняются два действия:

1. ответ домножается на $n-i+1$;
2. ответ делится на $i$, то есть домножается на обратный к $i$ элемент.

Получается следующий переход:

$$
answ
\leftarrow
answ\cdot(n-i+1)\cdot i^{-1}
\pmod{mod}.
$$

Если каждый обратный элемент вычислять быстрым возведением в степень, общее время работы составит

$$
O\bigl(\min(k,n-k)\log mod\bigr).
$$

Этот способ особенно полезен, когда $n$ велико, но меньшая из величин $k$ и $n-k$ невелика.

Полные реализации: [C++](examples/example-03.cpp) и [Python3](examples/example-03.py).

<details>
<summary><strong>C++: одно сочетание при небольшом k</strong></summary>

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll mod = 1000000007;
ll power(ll a, ll exponent) {
    ll answ = 1;
    while (exponent > 0) {
        if (exponent % 2 == 1) answ = answ * a % mod;
        a = a * a % mod;
        exponent /= 2;
    }
    return answ;
}
main() {
    int n, k; cin >> n >> k;
    int limit = min(k, n - k);
    // Последовательно домножаем числитель и делим на очередной знаменатель.
    ll answ = 1;
    for (int i = 1; i <= limit; i++) {
        answ = answ * (n - i + 1) % mod;
        answ = answ * power(i, mod - 2) % mod;
    }
    cout << answ << '\n';
}
```

</details>

<details>
<summary><strong>Python3: одно сочетание при небольшом k</strong></summary>

```python
mod = 10 ** 9 + 7

answ = 1
for i in range(1, limit + 1):
    answ = answ * (n - i + 1) % mod
    answ = answ * pow(i, -1, mod) % mod
print(answ)
```

</details>


> Все знаменатели должны иметь обратные элементы. Поэтому описанный способ напрямую применяется при $\min(k,n-k)<mod$.
>
> Для более общих ограничений могут потребоваться дополнительные методы, например теорема Лукаса.

## 2.9. Факториалы и обратные факториалы

Если нужно ответить на много запросов вида $\binom{n}{k}$, вычислять каждое сочетание циклом слишком долго. В этом случае удобно заранее подготовить факториалы и обратные факториалы.

По определению

$$
\binom{n}{k}
=
\frac{n!}{k!(n-k)!}.
$$

Заменим деление умножением на обратные элементы:

$$
\binom{n}{k}
\equiv
n!\cdot(k!)^{-1}\cdot((n-k)!)^{-1}
\pmod{mod}.
$$

Сначала предподсчитаем факториалы:

$$
fact[i]=i!\bmod mod.
$$

Они вычисляются последовательно:

$$
fact[0]=1,
$$

$$
fact[i]=fact[i-1]\cdot i\bmod mod.
$$

Затем найдём обратный факториал для наибольшего значения:

$$
invFact[maxN]
=
fact[maxN]^{mod-2}
\bmod mod.
$$

Остальные обратные факториалы можно восстановить движением вниз. Поскольку

$$
i!=(i-1)!\cdot i,
$$

для обратных значений выполняется

$$
((i-1)!)^{-1}=(i!)^{-1}\cdot i.
$$

Следовательно,

$$
invFact[i-1]
=
invFact[i]\cdot i
\bmod mod.
$$

После предподсчёта каждое сочетание вычисляется за $O(1)$:

$$
\binom{n}{k}
=
fact[n]\cdot invFact[k]\cdot invFact[n-k]
\bmod mod.
$$

Итоговая сложность:

- $O(maxN)$ времени на предподсчёт;
- $O(maxN)$ памяти;
- $O(1)$ времени на каждый запрос.

> [!IMPORTANT]
> Этот способ требует, чтобы выполнялось условие $maxN<mod$.
>
> Если $maxN\ge mod$, то один из факториалов станет равен нулю по модулю. У нуля нет обратного элемента, поэтому описанная схема перестанет работать.

Полные реализации:

- [C++](examples/example-02.cpp);
- [Python3](examples/example-02.py).

<details>
<summary><strong>C++: факториалы и обратные факториалы</strong></summary>

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll mod = 1000000007;
ll power(ll a, ll exponent) {
    ll answ = 1;
    while (exponent > 0) {
        if (exponent % 2 == 1) answ = answ * a % mod;
        a = a * a % mod;
        exponent /= 2;
    }
    return answ;
}
main() {
    int maxN, q; cin >> maxN >> q;
    // Предподсчитываем факториалы до наибольшей границы запросов.
    vector<ll> fact(maxN + 1), invFact(maxN + 1);
    fact[0] = 1;
    for (int i = 1; i <= maxN; i++)
        fact[i] = fact[i - 1] * i % mod;
    // Один обратный факториал восстанавливает все остальные движением вниз.
    invFact[maxN] = power(fact[maxN], mod - 2);
    for (int i = maxN; i >= 1; i--)
        invFact[i - 1] = invFact[i] * i % mod;
    // Для каждого запроса подставляем три предподсчитанных значения в формулу.
    while (q --> 0) {
        int n, k; cin >> n >> k;
        if (k < 0 || k > n) cout << 0 << '\n';
        else cout << fact[n] * invFact[k] % mod * invFact[n - k] % mod << '\n';
    }
}
```

## 2.10. Какой способ выбрать

Теперь у нас есть три способа вычислять сочетания.

| Условия | Подход | Время |
|---|---|---:|
| Размеры таблицы невелики | Динамика по путям | $O(nk)$ |
| Нужно одно сочетание, а $k$ или $n-k$ мало | Последовательное умножение и деление | $O(\min(k,n-k)\log mod)$ |
| Запросов много и все значения $n$ меньше модуля | Факториалы и обратные факториалы | $O(maxN)$ на предподсчёт и $O(1)$ на запрос |

Динамика лучше всего показывает комбинаторный смысл сочетаний. Последовательная формула подходит для одного запроса с небольшим $k$. Факториалы и обратные факториалы становятся основным инструментом, когда сочетания нужно вычислять много раз.

На этом этапе у нас уже есть все базовые средства для работы с комбинаторными формулами по простому модулю. В следующей главе мы применим их к задачам о путях по сетке и научимся заменять динамику прямым вычислением количества маршрутов.
