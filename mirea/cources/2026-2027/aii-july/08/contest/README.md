# Разбор задач

## A. Удали число

<details>
<summary>Текстовый разбор</summary>

После удаления одного элемента минимум оставшихся чисел изменится только в одном случае: если удалён единственный минимальный элемент массива.

Если минимум встречается хотя бы два раза, после удаления любого одного элемента хотя бы одна его копия останется. Поэтому все индексы дают одинаковый, а значит оптимальный результат. Если минимум единственный, удалить нужно именно его.

Достаточно найти минимум, число его вхождений и позицию первого вхождения. Асимптотика: $O(n)$ по времени и $O(n)$ по памяти на хранение массива.

</details>

<details>
<summary>Решение на C++</summary>

```cpp
// Чтобы сделать минимум оставшихся чисел как можно больше, требуется удалить наименьший
// элемент в массиве. Поэтому найдём минимум, его позицию и его количество. Если в массиве
// два и более наименьших элемента, то что бы мы не делали, ответ мы не уменьшим, поэтому
// выводим все индексы массива, так как удаление любого элемента не меняет ответ. Если в
// массиве ровно один минимум, то выводим его индекс.
#include <bits/stdc++.h>
using namespace std;
void solve() {
    // читаем массив:
    int n; cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++)
        cin >> a[i];
    // находим минимум, его позицию и количество:
    int pos = int(min_element(a.begin(), a.end()) - a.begin());
    int mn = a[pos];
    int cnt = 0;
    for (int i = 0; i < n; i++)
        cnt += (a[i] == mn);
    // если количество >= 2, то любой индекс можно удалить:
    if (cnt >= 2) {
        cout << n << '\n';
        for (int i = 1; i <= n; i++)
            cout << i << ' ';
        cout << '\n';
    } else {
        // иначе удаляем один единственный элемент - минимум в массиве:
        cout << "1\n" << pos+1 << '\n';
    }
}
main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int tt; cin >> tt;
    while (tt --> 0) solve();
}
```

## B. Склад

<details>
<summary>Текстовый разбор</summary>

Площадь коробки равна $w \times h$. Сами ширина и высота после добавления не нужны, поэтому будем хранить только площади и их префиксные суммы. В элементе `s[i]` лежит сумма площадей первых $i$ коробок.

Добавление коробки продолжает массив префиксных сумм, удаление последней коробки удаляет последний элемент массива `s`. Сумма последних $k$ площадей равна разности полной суммы и суммы до этих $k$ коробок, т.е. $s[m] - s[m-k]$.

Асимптотика: $O(n+q)$ по времени и $O(n+q)$ по памяти.

</details>

<details>
<summary>Решение на C++</summary>

```cpp
// Будем поддерживать префиксные суммы для площадей коробок. Они позволяют добавлять
// новую коробку в конец, удалять коробку с конца, а также считать сумму на любом подотрезке,
// в том числе и на суффиксе длины k.
#include <bits/stdc++.h>
#include <cassert>
using namespace std;
void solve() {
    // читаем данные и считаем префиксные суммы: i-й элемент вектора будет равен
    // сумме площадей всех коробок с номерами от 0 до i-1.
    int n, q; cin >> n >> q;
    vector<int64_t> s = {0};
    for (int i = 0; i < n; i++) {
        int wi, hi; cin >> wi >> hi;
        s.push_back(s.back() + wi * 1LL * hi);
    }
    // обрабатываем запросы:
    while (q --> 0) {
        char t; cin >> t;
        if (t == '?') {
            // считаем сумму на отрезке через префиксные суммы:
            int k; cin >> k;
            cout << s.back() - s[s.size() - 1 - k] << '\n';
        } else if (t == '+') {
            // добавляем новый элемент в конец, пересчитывая префиксные суммы:
            int wi, hi; cin >> wi >> hi;
            s.push_back(s.back() + wi * 1LL * hi);
        } else {
            // удаляем самый крайний элемент:
            assert(t == '-');
            s.pop_back();
        }
    }
}
main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int tt; cin >> tt;
    while (tt --> 0) solve();
}
```

## C. Удаление подотрезка

<details>
<summary>Текстовый разбор</summary>

Выгодно удалить подотрезок ровно длины $k$: дополнительное удалённое число не может уменьшить минимум среди оставшихся.

Пусть удаляется отрезок $[i, i+k-1]$. Тогда остаются префикс до него и суффикс после него.

Заранее посчитаем `pref[i]` — минимум на первых $i$ элементах — и `suff[i]` — минимум на суффиксе, начинающемся с позиции $i$. После удаления отрезка ответ равен $\min(pref[i-1], suff[i+k])$.

Переберём все возможные начала $i$ и выберем максимальное из полученных значений. Служебное значение $+\infty$ в массиве позволяет одинаково обработать удаление у левой и правой границы.

Асимптотика: $O(n)$ по времени и $O(n)$ по памяти.

</details>

<details>
<summary>Решение на C++</summary>

```cpp
// Нам выгодно всегда удалять подотрезок длины k, так как чем больше элементов мы удалим,
// тем больше будет итоговый минимум массива. Переберём все подотрезки длины k и посчитаем
// ответ, который получится после удаления этого отрезка. Пусть мы хотим удалить отрезок
// [i, i+k-1]. Тогда в массиве останутся префикс [1 .. i-1] и суффикс [i+k .. n]. Чтобы
// быстро считать минимум, нам нужно предподсчитать минимальный элемент на каждом префиксе,
// на каждом суффиксе, а затем брать минимум из pref[i-1] и suff[i+k].
#include <bits/stdc++.h>
#include <cassert>
using namespace std;
const int inf = (int)1e9+7;
void solve() {
    int n, k; cin >> n >> k;
    vector<int> a(1+n+1, inf);
    for (int i = 1; i <= n; i++)
        cin >> a[i];
    // считаем минимум на префиксе:
    vector<int> pref(1+n+1, inf);
    for (int i = 1; i <= n; i++)
        pref[i] = min(pref[i-1], a[i]);
    // считаем минимум на суффиксе:
    vector<int> suff(1+n+1, inf);
    for (int i = n; i >= 1; i--)
        suff[i] = min(suff[i+1], a[i]);
    // считаем ответ: выгодно всегда удалять подотрезок длины k
    int answ = -inf;
    for (int i = 1; i + k - 1 <= n; i++)
        answ = max(answ, min(pref[i-1], suff[i+k]));
    cout << answ << '\n';
}
main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int tt; cin >> tt;
    while (tt --> 0) solve();
}
```

Массивы создаются с запасом и заполняются значением `inf`:

```cpp
vector<int> a(1+n+1, inf);
vector<int> pref(1+n+1, inf);
vector<int> suff(1+n+1, inf);
```

Поэтому `pref[0]` корректно обозначает минимум пустого префикса, а `suff[n+1]` — минимум пустого суффикса. Например, если удаляем последние $k$ элементов, выражение `suff[i+k]` обращается именно к `suff[n+1]`.

```cpp
for (int i = 1; i + k - 1 <= n; i++)
```

перебирает все начала отрезка длины $k$. Внутри `pref[i-1]` — минимум слева от удаляемого отрезка, а `suff[i+k]` — минимум справа от него.

## D. Медиана после вставок

<details>
<summary>Текстовый разбор</summary>

Нижняя медиана отсортированного множества размера $m$ имеет индекс $\left\lfloor\frac{m-1}{2}\right\rfloor$. Её нужно выводить после каждой вставки.

**Первый способ.** Храним левую и правую половины множества. Все числа из `left` не больше всех чисел из `right`. Размеры половин отличаются не более чем на один, причём в `left` элементов не меньше. Тогда нижняя медиана всегда равна последнему элементу `left`. При вставке добавим число в подходящую половину и восстановим баланс переносом граничного элемента.

**Второй способ.** Прочитаем все начальные числа и все вставки, отсортируем их, а затем пойдём по запросам справа налево. В обратном порядке каждая вставка превращается в удаление. Для полного множества (финального массива) медиана известна сразу. После удаления одного числа её позиция сдвигается не более чем к одному соседу слева или справа.

Соседей храним в двусвязном списке, заданном массивами `Prev` и `Next` над отсортированным массивом координат. Удаление узла занимает $O(1)$, а его позиция находится бинарным поиском.

Асимптотика обоих способов: $O((n+q)\log(n+q))$ по времени и $O(n+q)$ по памяти.

</details>

<details>
<summary>Решение D-1 на C++</summary>

```cpp
// Будем поддерживать множество элементов в порядке возрастания, но хранить отдельно его
// левую и правую половины. Тогда медиана будет стоять в конце левой половины. Перед вставкой
// нового элемента мы сначала определяем, в какую половину он попадает, вставляем в неё, а
// затем мы делаем размеры половин примерно равными, перекидывая из начала правой половины в
// конец левой, или из конца левой половины в начало правой.
#include <bits/stdc++.h>
#include <cassert>
using namespace std;
void solve() {
    set<int> left, right;
    auto insertAndRebalance = [&](int x) {
        // функция вставляет элемент и приводит баланс между размерами половин в порядок
        // половины уже отсортированы. Нужно определить, куда попадает x, и вставить его:
        if (left.size() && x <= *left.rbegin())
            left.insert(x);
        else
            right.insert(x);
        // перекидываем из левой половины в правую:
        while (left.size() > right.size()+1) {
            right.insert(*left.rbegin());
            left.erase(--left.end());
        }
        // перекидываем из правой половины в левую:
        while (right.size() > left.size()) {
            left.insert(*right.begin());
            right.erase(right.begin());
        }
    };
    // читаем данные и вставляем их в множество:
    int n, q; cin >> n >> q;
    for (int i = 0; i < n; i++) {
        int x; cin >> x;
        insertAndRebalance(x);
    }
    // обрабатываем запросы:
    while (q --> 0) {
        int x; cin >> x;
        insertAndRebalance(x);
        cout << *left.rbegin() << ' ';
    }
    cout << '\n';
}
main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int tt; cin >> tt;
    while (tt --> 0) solve();
}
```

</details>

<details>
<summary>Разбор решения D-1 на C++</summary>

После каждого вызова `insertAndRebalance` поддерживается инвариант:

```cpp
left.size() == right.size() || left.size() == right.size()+1
```

Все элементы `left` не больше всех элементов `right`. Поэтому, когда элементов чётное число, половины имеют равный размер, а когда нечётное — в `left` ровно на один элемент больше. В обоих случаях нижняя медиана находится в конце `left`:

```cpp
*left.rbegin()
```

Если левая половина стала слишком большой, её последний элемент переносится в начало правой; если правая стала больше, её первый элемент переносится в конец левой. Оба переноса сохраняют общий отсортированный порядок.

</details>

<details>
<summary>Решение D-2 на C++</summary>

```cpp
// Прочитаем все числа, которые когда-либо появятся в множестве, и отсортируем их. Затем
// рассмотрим запросы в обратном порядке: каждая прежняя вставка станет удалением. Медиану
// полного множества легко найти в отсортированном массиве. При удалении одного числа
// нижняя медиана сдвигается не более чем на одного соседа. Соседей храним в двусвязном
// списке, реализованном двумя массивами Prev и Next.
#include <bits/stdc++.h>
using namespace std;
void solve() {
    // читаем начальные числа и запросы:
    int n, q; cin >> n >> q;
    vector<int> initial(n), queries(q), x;
    for (int i = 0; i < n; i++) {
        cin >> initial[i];
        x.push_back(initial[i]);
    }
    for (int i = 0; i < q; i++) {
        cin >> queries[i];
        x.push_back(queries[i]);
    }
    // сортируем все числа, которые будут в множестве после последней вставки:
    sort(x.begin(), x.end());
    // строим двусвязный список отсортированных чисел:
    vector<int> Prev(n + q, -1), Next(n + q, -1);
    for (int i = 0; i + 1 < n + q; i++)
        Prev[i+1] = i, Next[i] = i+1;
    // в полном множестве находим нижнюю медиану:
    int median = (n + q - 1) / 2;
    vector<int> answ(q);
    // обрабатываем запросы с конца: вставка превращается в удаление:
    for (int queryId = q-1; queryId >= 0; queryId--) {
        // текущая нижняя медиана и есть ответ после этой вставки:
        answ[queryId] = x[median];
        // находим элемент, который теперь нужно удалить:
        int xi = int(lower_bound(x.begin(), x.end(), queries[queryId]) - x.begin());
        int size = n + queryId + 1;
        // сдвигаем медиану до удаления, если её ранг изменится:
        if (size % 2 == 0 && xi <= median)
            median = Next[median];
        if (size % 2 == 1 && xi >= median)
            median = Prev[median];
        // связываем соседей друг с другом, удаляя xi:
        int pi = Prev[xi], ni = Next[xi];
        if (pi != -1) Next[pi] = ni;
        if (ni != -1) Prev[ni] = pi;
    }
    // выводим ответ:
    for (int i = 0; i < q; i++)
        cout << answ[i] << ' ';
    cout << '\n';
}
main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int tt; cin >> tt;
    while (tt --> 0) solve();
}
```

<details>
<summary>Разбор решения D-2 на C++</summary>

Перед удалением размер текущего множества равен `size`. Если `size` чётный, после удаления нижняя медиана нового нечётного множества сдвигается вправо только тогда, когда удалён элемент слева от неё или сама медиана:

```cpp
if (size % 2 == 0 && xi <= median)
    median = Next[median];
```

Если `size` нечётный, новая нижняя медиана в множестве чётного размера сдвигается влево только при удалении элемента справа от неё или самой медианы:

```cpp
if (size % 2 == 1 && xi >= median)
    median = Prev[median];
```

После сдвига массивы `Prev` и `Next` исключают удаляемый индекс из списка. Бинарный поиск остаётся корректным: массив `x` не меняется, меняются только связи между ещё не удалёнными индексами.

</details>

<details>
<summary>Решение D-2 на Python3</summary>

```python
# Прочитаем все числа, которые когда-либо появятся в множестве, и отсортируем их. Затем
# рассмотрим запросы в обратном порядке: каждая прежняя вставка станет удалением. Медиану
# полного множества легко найти в отсортированном массиве. При удалении одного числа
# нижняя медиана сдвигается не более чем на одного соседа. Соседей храним в двусвязном
# списке, реализованном двумя массивами Prev и Next.
from bisect import bisect_left


def solve():
    # читаем начальные числа и запросы:
    n, q = map(int, input().split())
    initial = list(map(int, input().split()))
    queries = list(map(int, input().split()))
    x = initial + queries
    # сортируем все числа, которые будут в множестве после последней вставки:
    x.sort()
    # строим двусвязный список отсортированных чисел:
    Prev = [-1] * (n + q)
    Next = [-1] * (n + q)
    for i in range(n + q - 1):
        Prev[i + 1] = i
        Next[i] = i + 1
    # в полном множестве находим нижнюю медиану:
    median = (n + q - 1) // 2
    answ = [0] * q
    # обрабатываем запросы с конца: вставка превращается в удаление:
    for query_id in range(q - 1, -1, -1):
        # текущая нижняя медиана и есть ответ после этой вставки:
        answ[query_id] = x[median]
        # находим элемент, который теперь нужно удалить:
        xi = bisect_left(x, queries[query_id])
        size = n + query_id + 1
        # сдвигаем медиану до удаления, если её ранг изменится:
        if size % 2 == 0 and xi <= median:
            median = Next[median]
        if size % 2 == 1 and xi >= median:
            median = Prev[median]
        # связываем соседей друг с другом, удаляя xi:
        pi = Prev[xi]
        ni = Next[xi]
        if pi != -1:
            Next[pi] = ni
        if ni != -1:
            Prev[ni] = pi
    # выводим ответ:
    for value in answ:
        print(value, end=' ')
    print()


tt = int(input())
while tt > 0:
    solve()
    tt -= 1
```

</details>

<details>
<summary>Разбор решения D-2 на Python3</summary>

`bisect_left(x, queries[query_id])` находит индекс удаляемого числа в неизменяемом отсортированном массиве `x`. Само число уже могло исчезнуть из текущего множества только в прямом направлении, поэтому в обратном обходе оно в этот момент ещё присутствует в двусвязном списке.

Связи узла обновляются отдельно:

```python
if pi != -1:
    Next[pi] = ni
if ni != -1:
    Prev[ni] = pi
```

У первого элемента нет левого соседа, а у последнего — правого, поэтому проверка `-1` не позволяет обратиться к последнему элементу списка по отрицательному индексу Python. В отличие от C++, индекс `-1` в Python допустим и без этой проверки дал бы ошибочную связь.

</details>

## E. Чередующийся стек

<details>
<summary>Текстовый разбор</summary>

Из каждого массива числа можно брать только с конца. Поэтому порядок чисел, взятых первым игроком, всегда равен $a_n, a_{n-1}, \ldots, a_1$, а у второго игрока — $b_n, b_{n-1}, \ldots, b_1$. Остаётся выбрать порядок, в котором эти две последовательности перемежаются.

Запустим рекурсивный перебор. Состояние задаётся числами ещё не взятых элементов из обоих массивов и последним числом на столе. На каждом шаге можно взять верхнее число первого или второго массива, только если его чётность отличается от чётности последнего числа. Если оба массива пусты, найден один подходящий итоговый список.

Раннее отсечение по чётности не даёт рекурсии продолжать заведомо неправильный список. Поскольку $n$ мало, такого перебора с возвратом и отсечением достаточно.

Асимптотика: $O(S)$ по времени, где $S$ — число посещённых состояний рекурсии, и $O(n)$ по памяти на стек рекурсии.

</details>

<details>
<summary>Разбор решения на C++</summary>

Вектор `c` хранит текущий список чисел на столе только для проверки его последнего элемента. Перед рекурсивным вызовом новое число добавляется:

```cpp
c.push_back(a[n1-1]);
dfs(n1-1, n2);
c.pop_back();
```

После возврата `pop_back()` откатывает состояние точно к виду до выбора. Поэтому следующая ветвь рекурсии не видит число, добавленное в предыдущей ветви. Проверка `c.empty()` разрешает первый ход без сравнения чётностей.

</details>

<details>
<summary>Разбор решения на Python3</summary>

Вложенная функция меняет счётчик `answ`, определённый в `solve`, поэтому ему требуется объявление:

```python
nonlocal answ
```

Список `c` используется для возврата состояния так же, как стек:

```python
c.append(b[n2 - 1])
dfs(n1, n2 - 1)
c.pop()
```

Ветвь рекурсии добавляет число, рекурсивно продолжает список, а затем удаляет то же число. Условие `not c` отдельно обрабатывает первый элемент: до него на столе нет соседа, с которым нужно сравнивать чётность.

</details>
<details>
<summary>Решение на C++</summary>

```cpp
// Если мы обозначим ход первого игрока как "0", а ход второго как "1", то последовательность
// ходов в игре однозначно кодируется бинарной строкой длины "2n", содержащей "n" нулей и "n"
// единиц. Рекурсивно переберём все двоичные строки, проверяя, может ли выбранный игрок
// сделать ход: для этого сравниваем чётность его числа и числа на столе.
#include <bits/stdc++.h>
using namespace std;
void solve() {
    // читаем массивы
    int n; cin >> n;
    vector<int> a(n), b(n);
    for (auto &it : a) cin >> it;
    for (auto &it : b) cin >> it;
    // запускаем рекурсию
    int64_t answ = 0;
    vector<int> c;
    function<void(int,int)> dfs = [&](int n1, int n2) {
        // если элементы закончились, выходим из рекурсии:
        if (n1 == 0 && n2 == 0) {
            answ++;
            return;
        }
        // пытаемся взять из первого массива:
        if (n1 > 0 && (c.empty() || abs(c.back()) % 2 != abs(a[n1-1]) % 2)) {
            c.push_back(a[n1-1]);
            dfs(n1-1, n2);
            c.pop_back();
        }
        // пытаемся взять из второго массива:
        if (n2 > 0 && (c.empty() || abs(c.back()) % 2 != abs(b[n2-1]) % 2)) {
            c.push_back(b[n2-1]);
            dfs(n1, n2-1);
            c.pop_back();
        }
    };
    // вызываем рекурсивную функцию:
    dfs(n, n);
    // выводим ответ:
    cout << answ << '\n';
}
main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int tt; cin >> tt;
    while (tt --> 0) solve();
}
```
