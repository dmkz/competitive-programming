# Разбор задач

## A. Разложение числа

<details>
<summary>Текстовый разбор</summary>

Попробуем строить разложение постепенно: выберем первое слагаемое, затем второе и так далее. После того как уже выбраны числа с суммой $s$, остаётся разложить число $n-s$. Разложим остаток рекурсивно.

Осталось не допустить убываний. Если последним числом записан $x$, то следующее слагаемое не может быть меньше $x$. Поэтому в рекурсивной функции достаточно помнить текущее разложение и оставшуюся сумму, а новые числа перебирать от последнего выбранного до этой суммы. Когда остаток стал равен нулю, построено подходящее разложение.

Такая подход сразу генерирует ответы в лексикографическом порядке.

Асимптотика: $O(\text{total output})$ по времени и $O(n)$ по памяти.

</details>

<details>
<summary>Решение на C++</summary>

```cpp
// Запустим рекурсивный перебор для поиска монотонно неубывающих последовательностей
// с суммой элементов, равной числу "n". Перебирая новое число, мы начинаем не с единицы, а
// со значения, равного предыдущему, чтобы сразу строить монотонно неубывающий ответ.
#include <bits/stdc++.h>
using namespace std;
vector<int> answ;
void dfs(int n) {
    if (n == 0) {
        // если мы набрали ту сумму, которую хотели, то выводим очередное разбиение:
        for (auto it : answ)
            cout << it << ' ';
        cout << '\n';
        return;
    }
    // начинаем перебор с последнего слагаемого, чтобы удовлетворить монотонность:
    // a[0] <= a[1] <= a[2] <= ...
    for (int x = answ.size() ? answ.back() : 1; x <= n; x++) {
        // кладём новое слагаемое:
        answ.push_back(x);
        // делаем рекурсивный вызов, уменьшая сумму, которую нужно набрать:
        dfs(n - x);
        // возвращаем всё как было:
        answ.pop_back();
    }
}
void solve() {
    int n; cin >> n;
    dfs(n);
    cout << '\n';
}
main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int tt; cin >> tt;
    while (tt --> 0) solve();
}
```

</details>

## B. Расставь знаки!

<details>
<summary>Текстовый разбор</summary>

У каждого числа есть ровно два варианта знака. При $n \le 24$ можно честно перебрать все $2^n$ строк из символов `+` и `-`: на позиции $i$ сначала поставить `+`, а затем поставить `-`.

Чтобы не пересчитывать всю сумму в листе рекурсии, будем хранить величину, которую ещё нужно получить. Пусть до цели осталось $x$. После выбора `+a_i` осталось набрать $x-a_i$, а после выбора `-a_i` &ndash; $x+a_i$. Когда все знаки расставлены, строка подходит тогда и только тогда, когда остаток, который мы хотели набрать, стал равен нулю.

Внутри рекурсии считаем каждый подходящий вариант. Первую подходящую строку сохраним отдельно. Она уже будет лексикографически первой: обход всегда сначала выбирает `+`, а `+` меньше `-`.

Асимптотика: $O(2^n)$ по времени и $O(n)$ по памяти.

</details>

<details>
<summary>Решение на C++</summary>

```cpp
// Напишем рекурсивный перебор, чтобы перебрать все 2^n вариантов расстановки знаков.
// Если мы ставим "+" перед a[i], то сумма увеличивается на a[i], иначе уменьшается.
// Если в самом конце получили ту сумму, которую хотели, то обновляем ответ.
// В данном решении текущая сумма не хранится. Вместо неё хранится величина, которую
// нам ещё осталось набрать.
#include <bits/stdc++.h>
using namespace std;
vector<int> a;
string s;
string answ;
int cnt;
void clear() {
    a = {};
    s = "";
    answ = "";
    cnt = 0;
}
void dfs(int i, int64_t x) {
    if (i == a.size()) {
        if (x == 0) { // нашли ответ
            cnt++;
            if (answ.empty())
                answ = s;
        }
        return;
    }
    // пробуем плюс
    s += '+';
    dfs(i+1, x - a[i]);
    s.pop_back();
    // пробуем минус
    s += '-';
    dfs(i+1, x + a[i]);
    s.pop_back();
}
void solve() {
    // читаем данные
    int n; int64_t x;
    cin >> n >> x;
    clear();
    a.resize(n);
    for (auto &it : a)
        cin >> it;
    dfs(0, x);
    if (cnt == 0) {
        cout << "0\nNO SOLUTION\n";
    } else {
        cout << cnt << '\n' << answ << '\n';
    }
}
main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int tt; cin >> tt;
    while (tt --> 0) solve();
}
```

</details>

<details>
<summary>Разбор решения на C++</summary>

Основное отличие параметра `x` от текущей суммы видно в двух вызовах:

```cpp
dfs(i+1, x - a[i]);
...
dfs(i+1, x + a[i]);
```

`x` означает, какую величину ещё нужно получить. Выбор `+a[i]` добавляет это число к будущей сумме, поэтому нужный остаток уменьшается. Выбор `-a[i]`, наоборот, уменьшает будущую сумму, поэтому остаток увеличивается.

Строка `s` строится с возвратом: добавляем очередной знак, запускаем рекурсию и сразу удаляем этот знак через `pop_back()`. Поэтому перед переходом в следующую ветвь строка снова содержит ровно тот префикс, который был до выбора знака.

</details>

<details>
<summary>Разбор решения на Python3</summary>

Здесь список `s` хранит текущую строку знаков. Фрагмент

```python
s.append('+')
dfs(i + 1, x - a[i])
s.pop()
```

сначала добавляет знак к текущему префиксу, а после возврата из рекурсии убирает его. Поэтому при переходе к ветви с `-` список содержит тот же префикс, что и до выбора `+`.

Параметр `x` хранит не накопленную сумму, а остаток до цели. После `+a[i]` нужен остаток `x - a[i]`, после `-a[i]` &ndash; `x + a[i]`. В листе рекурсии условие `x == 0` означает, что выбранные знаки дали требуемую сумму.

</details>

## C. Две почти равные команды

<details>
<summary>Текстовый разбор</summary>

Для каждого человека нужно принять одно из двух решений: отправить его в первую или во вторую команду. При $n \le 26$ можно перебрать такие решения рекурсией, но сразу следить за размерами команд: в первой должно оказаться ровно $k$ человек, а во второй &ndash; ровно $n-k$.

Можно поддерживать разность текущих сумм сил команд. Если очередной человек идёт в первую команду, прибавляем его силу к разности, а если во вторую &ndash; вычитаем. В конце обхода модуль получившейся разности и есть кандидат на ответ.

Рекурсивную ветвь можно не продолжать, если первая команда уже набрала $k$ человек или вторая &ndash; $n-k$: дальнейший выбор в такую команду всё равно нарушит условие.

Асимптотика: $O(C_n^k)$ по времени и $O(n)$ по памяти.

</details>

<details>
<summary>Решение на C++</summary>

```cpp
// Рекурсивно перебираем все варианты разбиения людей на команды. Рассматриваем два варианта:
// 1. Включаем i-го человека в первую команду;
// 2. Включаем i-го человека во вторую команду.
// Храним набранную разницу между силами двух команд. Ответ - модуль этой разности.
#include <bits/stdc++.h>
using namespace std;
void solve() {
    // читаем данные
    int n, k; cin >> n >> k;
    vector<int> a(n);
    for (int i = 0; i < n; i++)
        cin >> a[i];
    // запускаем поиск решения:
    int64_t diff = 0, answ = 1e18L;
    function<void(int,int,int)> dfs = [&](int i, int n1, int n2){
        if (i == n) {
            if (n1 == k)
                answ = min(answ, abs(diff));
            return;
        }
        // включаем i-го человека в первую команду:
        if (n1 < k) {
            diff += a[i];
            dfs(i+1, n1+1, n2);
            diff -= a[i];
        }
        // включаем i-го человека во вторую команду:
        if (n2 < n - k) {
            diff -= a[i];
            dfs(i+1, n1, n2+1);
            diff += a[i];
        }
    };
    dfs(0, 0, 0);
    cout << answ << '\n';
}
main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int tt; cin >> tt;
    while (tt --> 0) solve();
}
```

</details>

<summary>Решение на Python3</summary>

```python
# Рекурсивно перебираем все варианты разбиения людей на команды. Рассматриваем два варианта:
# 1. Включаем i-го человека в первую команду;
# 2. Включаем i-го человека во вторую команду.
# Храним набранную разницу между силами двух команд. Ответ - модуль этой разности.
def solve():
    # читаем данные
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    def dfs(i, n1, n2, diff):
        nonlocal answ
        if i == n:
            if n1 == k:

        # включаем i-го человека в первую команду:
        if n1 < k:
            dfs(i + 1, n1 + 1, n2, diff + a[i])
        # включаем i-го человека во вторую команду:
        if n2 < n - k:
            dfs(i + 1, n1, n2 + 1, diff - a[i])

    dfs(0, 0, 0, 0)
    print(answ)


tt = int(input())
while tt > 0:
    solve()
    tt -= 1
```

<details>
<summary>Разбор решения на C++</summary>

Лямбда захватывает переменную `diff` по ссылке, поэтому её значение меняется прямо перед рекурсивным вызовом:

```cpp
diff += a[i];
dfs(i+1, n1+1, n2);
diff -= a[i];
```

Последняя строка обязательна. Она возвращает `diff` к значению до выбора команды для $i$-го человека. Тогда следующая ветвь начинается с правильной разности, а не с результата предыдущей ветви.

Размеры команд передаются параметрами `n1` и `n2`. Благодаря проверкам `n1 < k` и `n2 < n-k` не возникает ветвей, в которых команда уже переполнена.

</details>

<details>
<summary>Разбор решения на Python3</summary>

В Python разность `diff` передаётся параметром функции:

```python
dfs(i + 1, n1 + 1, n2, diff + a[i])
dfs(i + 1, n1, n2 + 1, diff - a[i])
```

Целые числа в Python неизменяемы, поэтому каждый вызов получает своё значение `diff`. После возврата вручную восстанавливать разность не нужно: переменная вызывающей функции не менялась.

Переменная `answ` находится снаружи `dfs`, а строка `nonlocal answ` разрешает обновлять её внутри вложенной функции. Без `nonlocal` присваивание создало бы новую локальную переменную и минимум не сохранился бы.

</details>

Python3-версия повторяет тот же перебор, но на максимальных тестах не укладывается в ограничение времени и получает `Time Limit Exceeded`.

## D. Скобочная заготовка на Новый Год

<details>
<summary>Текстовый разбор</summary>

Правильность скобочной последовательности удобно проверять слева направо. Будем хранить баланс: число открывающих скобок, которые уже встретились, но ещё не закрылись. У правильного префикса баланс не бывает отрицательным, а у всей строки он обязан стать нулём.

Теперь можно строить строку рекурсией по позициям. На позиции, для которой символ уже зафиксирован, выбора нет, а на `?` пробуем заменить символ сначала на `(`, а потом на `)`. Ветвь с закрывающей скобкой разрешена только при положительном балансе: иначе появится неправильный префикс. В конце печатаем только строки с нулевым балансом.

Символ `(` лексикографически меньше `)`, поэтому такой порядок ветвей сразу даёт нужный порядок вывода.

Асимптотика: $O(C_n^{\lfloor n/2 \rfloor})$ по времени и $O(n)$ по памяти.

</details>

<details>
<summary>Решение на C++</summary>

```cpp
// Прочитаем шаблон скобочной строки и запустим рекурсивный перебор вариантов.
// Если позиция равна "?", то мы можем поставить как открывающую скобку, так и закрывающую.
// Если позиция равна "(" или ")", то ставим именно эту скобку.
// Поддерживаем баланс открытых скобок. Запрещено ставить закрывающую скобку, если баланс
// становится отрицательным. В конце перебора выводим те строки, баланс которых равен 0.
#include <bits/stdc++.h>
using namespace std;
void solve() {
    // читаем данные
    int n; cin >> n;
    string pattern; cin >> pattern;
    // запускаем рекурсию
    string s;
    bool was = false;
    function<void(int, int)> dfs = [&](int i, int balance) {
        if (i == n) {
            if (balance == 0) {
                cout << s << '\n';
                was = true;
            }
            return;
        }
        // ставим открывающую:
        if (pattern[i] != ')') {
            s.push_back('(');
            dfs(i+1, balance+1);
            s.pop_back();
        }
        // ставим закрывающую:
        if (pattern[i] != '(' && balance > 0) {
            s.push_back(')');
            dfs(i+1, balance-1);
            s.pop_back();
        }
    };
    dfs(0, 0);
    if (!was)
        cout << "NO SOLUTION\n";
    cout << '\n';
}
main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int tt; cin >> tt;
    while (tt --> 0) solve();
}
```

</details>

<summary>Решение на Python3</summary>

## E. Ферзи с запретами

<details>
<summary>Текстовый разбор</summary>

Так как два ферзя не могут стоять в одной строке, удобно ставить их сверху вниз: на очередной строке выбираем столбец для единственного нового ферзя. После выбора нужно быстро понять, какие позиции ниже уже бьются, не просматривая всю доску заново.

Достаточно помнить три множества: занятые столбцы и две группы диагоналей ($i+j=const$ и $i-j=const$). При $n \le 14$ каждое множество можно записать битовой маской (или `std::bitset`), где один установленный бит соответствует столбцу в текущей строке.

Входную карту доски тоже приведём к битовым маскам: построим маску разрешённых клеток. Доступны те разрешённые клетки, которые ещё не находятся под боем.

При переходе на следующую строку столбцы, находящиеся под боем, остаются теми же, а диагонали сдвигаются на один столбец влево (диагонали вида $i+j=const$) или вправо (диагонали вида $i-j=const$). 

Рекурсивно переберём все доступные позиции. Если строки закончились, получена одна подходящая расстановка.

Асимптотика: время зависит от числа посещённых состояний перебора с возвратом, память &ndash; $O(n)$ на стек рекурсии.

</details>

<details>
<summary>Решение на C++</summary>

```cpp
// Будем рекурсивно расставлять ферзей, двигаясь по строкам сверху вниз. Ферзь бьёт
// строку, столбец и две диагонали. Поддерживаем множество столбцов и диагоналей, которые
// находятся под боем. При переходе от row к row+1:
// 1. номера столбцов, находящихся под боем, не меняются;
// 2. диагонали вида row+col на доске сдвигаются на 1 влево;
// 3. диагонали вида row-col на доске сдвигаются на 1 вправо.
// Оптимальная скорость перебора достигается с использованием bitset и битовых сдвигов
// на один влево и на один вправо.

#pragma GCC optimize("Ofast")
#include <bits/stdc++.h>
using namespace std;

int n;
vector<string> board;
vector<bitset<32>> available;
int64_t answ;

void dfs(int row, bitset<32> usedCol, bitset<32> usedDiag1, bitset<32> usedDiag2) {
    if (row == n) {
        answ++;
        return;
    }
    bitset<32> canPut = available[row] & ~(usedCol | usedDiag1 | usedDiag2);
    for (int col = 0; col < n; col++)
        if (canPut[col]) {
            // копируем состояние поля:
            bitset<32> newUsedCol = usedCol;
            bitset<32> newUsedDiag1 = usedDiag1;
            bitset<32> newUsedDiag2 = usedDiag2;
            // отмечаем текущую клетку:
            newUsedCol[col] = 1;
            newUsedDiag1[col] = 1;
            newUsedDiag2[col] = 1;
            // при переходе от row к row+1: столбцы не меняются
            newUsedDiag1 <<= 1; // диагонали (row-col): вправо на доске, влево в маске
            newUsedDiag2 >>= 1; // диагонали (row+col): влево на доске, вправо в маске
            // рекурсивный вызов:
            dfs(row+1, newUsedCol, newUsedDiag1, newUsedDiag2);
        }
}

void solve() {
    // читаем исходные данные:
    cin >> n;
    board.resize(n);
    for (auto &it : board)
        cin >> it;
    // инициализируем вспомогательные данные:
    available.assign(n, 0);
    for (int row = 0; row < n; row++)
        for (int col = 0; col < n; col++)
            if (board[row][col] == '.')
                available[row][col] = 1;
    answ = 0;
    // запускаем рекурсивный перебор
    dfs(0, 0, 0, 0);
    // выводим ответ:
    cout << answ << '\n';
}
main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int tt; cin >> tt;
    while (tt --> 0) solve();
}
```

</details>

<details>
<summary>Разбор решения на C++</summary>

Ключевая строка строит маску доступных столбцов:

```cpp
bitset<32> canPut = available[row] & ~(usedCol | usedDiag1 | usedDiag2);
```

В `available[row]` стоят единицы только в разрешённых клетках. Объединение трёх `used`-масок отмечает все клетки, которые бьют ранее поставленные ферзи. После `~` единицы остаются в свободных столбцах, а `&` с `available[row]` убирает запрещённые клетки.

После выбора столбца диагональные маски сдвигаются:

```cpp
newUsedDiag1 <<= 1;
newUsedDiag2 >>= 1;
```

На строку ниже диагональ $row-col=const$ попадает в столбец правее, поэтому её биты сдвигаются влево через `<<`. Диагональ $row+col=const$ попадает в столбец левее, поэтому её биты сдвигаются вправо через `>>`. Сдвиг маски сразу отмечает все клетки следующей строки, которые будут биться по соответствующей диагонали.

</details>

<details>
<summary>Решение на Python3</summary>

```python
# Будем рекурсивно расставлять ферзей, двигаясь по строкам сверху вниз. Ферзь бьёт
# строку, столбец и две диагонали. Поддерживаем множество столбцов и диагоналей, которые
# находятся под боем. При переходе от row к row+1:
# 1. номера столбцов, находящихся под боем, не меняются;
# 2. диагонали вида row+col на доске сдвигаются на 1 влево;
# 3. диагонали вида row-col на доске сдвигаются на 1 вправо.
# Оптимальная скорость перебора достигается с использованием битовых масок и битовых сдвигов
# на один влево и на один вправо.
def solve():
    # читаем исходные данные:
    n = int(input())
    board = [input() for _ in range(n)]
    # инициализируем вспомогательные данные:
    available = [0] * n
    for row in range(n):
        for col in range(n):
            if board[row][col] == '.':
                available[row] |= 1 << col
    answ = 0

    def dfs(row, used_col, used_diag1, used_diag2):
        nonlocal answ
        if row == n:
            answ += 1
            return
        can_put = available[row] & ~(used_col | used_diag1 | used_diag2)
        for col in range(n):
            if can_put & (1 << col):
                # копируем состояние поля:
                new_used_col = used_col
                new_used_diag1 = used_diag1
                new_used_diag2 = used_diag2
                # отмечаем текущую клетку:
                new_used_col |= 1 << col
                new_used_diag1 |= 1 << col
                new_used_diag2 |= 1 << col
                # при переходе от row к row+1: столбцы не меняются
                new_used_diag1 <<= 1  # диагонали (row-col): вправо на доске, влево в маске
                new_used_diag2 >>= 1  # диагонали (row+col): влево на доске, вправо в маске
                # рекурсивный вызов:
                dfs(row + 1, new_used_col, new_used_diag1, new_used_diag2)

    # запускаем рекурсивный перебор
    dfs(0, 0, 0, 0)
    # выводим ответ:
    print(answ)


tt = int(input())
while tt > 0:
    solve()
    tt -= 1
```

</details>

<details>
<summary>Разбор решения на Python3</summary>

В Python битовая маска хранится в обычном целом числе. Проверка

```python
if can_put & (1 << col):
```

проверяет, установлен ли бит столбца `col`, то есть можно ли поставить туда ферзя. Операция `1 << col` создаёт число, в котором установлен только этот бит.

После выбора клетки три операции `|= 1 << col` добавляют столбец в каждую нужную маску. Диагональ $row-col=const$ при переходе вниз идёт вправо, поэтому её биты сдвигаются через `<<= 1`. Диагональ $row+col=const$ идёт влево, поэтому её биты сдвигаются через `>>= 1`. Так не требуется отдельно проверять координаты всех ранее поставленных ферзей.

</details>

Python3-версия на максимальных тестах не укладывается в ограничение времени и получает `Time Limit Exceeded`.
