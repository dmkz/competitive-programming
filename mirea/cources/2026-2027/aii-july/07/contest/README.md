# Разбор задач

## A. Тестируем лазер

<details>
<summary>Текстовый разбор</summary>

Лазер пробивает доски только слева направо. Если он пробил первые $i$ досок, то потратил ровно сумму $a_1 + a_2 + \ldots + a_i$. Значит, для мощности $x$ нужно найти наибольшее $i$, для которого эта сумма не превосходит $x$.

Заранее посчитаем префиксные суммы. Все стоимости положительны, поэтому префиксные суммы строго возрастают. Для каждого запроса остаётся бинарным поиском найти первую сумму, которая строго больше $x$. Число элементов, стоящих перед ней, и будет ответом.

Асимптотика: $O(n + q \log n)$ по времени и $O(n)$ по памяти.

</details>

<details>
<summary>Решение на C++</summary>

```cpp
// Для каждого x[j] нужно найти минимальный i такой, что x[j] < a[1] + a[2] + ... + a[i].
// Этот номер i будет равен первой доске, которую мы не сможем пробить. Чтобы быстро искать
// данный индекс, построим вектор префиксных-сумм и сделаем бинарный поиск в нём.
#include <bits/stdc++.h>
using namespace std;
void solve() {
    // читаем массив:
    int n, q; cin >> n >> q;
    vector<int> a(n);
    for (int i = 0; i < n; i++)
        cin >> a[i];
    // считаем префиксные суммы:
    vector<int64_t> s = {0};
    for (auto it : a)
        s.push_back(s.back() + it);
    // отвечаем на запросы: для заданного x нужно найти ближайший s[i] > x
    // используем для этого бинарный поиск (upper_bound)
    while (q --> 0) {
        int64_t x; cin >> x;
        cout << int(upper_bound(s.begin(), s.end(), x) - s.begin() - 1) << ' ';
    }
    cout << '\n';
}
main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int tt; cin >> tt;
    while (tt --> 0) solve();
}
```

</details>

<details>
<summary>Решение на Python3</summary>

```python
# Для каждого x[j] нужно найти минимальный i такой, что x[j] < a[1] + a[2] + ... + a[i].
# Этот номер i будет равен первой доске, которую мы не сможем пробить. Чтобы быстро искать
# данный индекс, построим вектор префиксных-сумм и сделаем бинарный поиск в нём.
from bisect import bisect_right


def solve():
    # читаем массив:
    n, q = map(int, input().split())
    a = list(map(int, input().split()))
    # считаем префиксные суммы:
    s = [0]
    for value in a:
        s.append(s[-1] + value)
    # отвечаем на запросы: для заданного x нужно найти ближайший s[i] > x
    # используем для этого бинарный поиск (bisect_right)
    for x in map(int, input().split()):
        print(bisect_right(s, x) - 1, end=' ')
    print()


tt = int(input())
while tt > 0:
    solve()
    tt -= 1
```

</details>

<details>
<summary>Разбор решения на C++</summary>

Вызов

```cpp
upper_bound(s.begin(), s.end(), x)
```

возвращает итератор на первый элемент, строго больший $x$. Если это `s[i]`, то подходят ровно суммы `s[0]`, `s[1]`, ..., `s[i-1]`, поэтому ответ равен разности итераторов минус один:

```cpp
int(upper_bound(s.begin(), s.end(), x) - s.begin() - 1)
```

Нулевой элемент `s[0] = 0` нужен, чтобы для мощности, которой не хватает на первую доску, ответом получилось $0$.

</details>

<details>
<summary>Разбор решения на Python3</summary>

Функция `bisect_right(s, x)` возвращает позицию сразу после всех элементов, не превосходящих $x$. Поэтому число таких элементов равно `bisect_right(s, x)`, но один из них – искусственная префиксная сумма $0$. Именно поэтому из результата вычитается единица:

```python
bisect_right(s, x) - 1
```

</details>

## B. Продуктивная вылазка за продуктами

<details>
<summary>Текстовый разбор</summary>

Нужно максимизировать количество купленных товаров, а не их суммарную стоимость. Поэтому выгодно покупать самые дешёвые товары.

Значит, отсортируем товары по цене и будем брать их в отсортированном порядке, пока хватает денег. Вместе с ценой сохраним исходный индекс товара, чтобы вывести выбранный набор.

Асимптотика: $O(n \log n)$ по времени и $O(n)$ по памяти.

</details>

<details>
<summary>Решение на C++</summary>

```cpp
// Чтобы набрать как можно больше товаров, нужно покупать самые дешёвые из них. Поэтому
// отсортируем пары (значение, индекс) в порядке возрастания значения и пройдём по ним,
// набирая товары до тех пор, пока не закончатся деньги. Запоминаем индексы купленных товаров.
#include <bits/stdc++.h>
using namespace std;
void solve() {
    // читаем элементы и сортируем пары (значение, индекс):
    int n; int64_t s;
    cin >> n >> s;
    vector<pair<int,int>> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i].first;
        a[i].second = i+1;
    }
    // сортируем пары лексикографически:
    sort(a.begin(), a.end());
    // формируем ответ: берём самые дешёвые товары, пока не кончились деньги
    vector<int> answ;
    for (const auto &[ai, i] : a)
        if (s >= ai) {
            s -= ai;
            answ.push_back(i);
        }
    // выводим ответ:
    cout << answ.size() << '\n';
    for (auto it : answ)
        cout << it << ' ';
    cout << '\n';
}
main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int tt; cin >> tt;
    while (tt --> 0) solve();
}
```

</details>

## C. Хороводоводы

<details>
<summary>Текстовый разбор</summary>

Для каждой строки посчитаем баланс: количество букв `g` минус количество букв `b`. После объединения двух хороводов количество девочек и мальчиков совпадает тогда и только тогда, когда сумма их балансов равна нулю.

Пусть $a_i$ равен балансу $i$-й строки. Нужно посчитать количество пар $(i,j)$ таких, что $a_i + a_j = 0$.

Значит, для строки с балансом $a_i = d$ нужно узнать, сколько строк имеют баланс $-d$. Сначала посчитаем частоту каждого баланса и сохраним в словарь. Затем для каждой строки временно уберём её из словаря частот, чтобы случайно не посчитать пару $(i,i)$, затем возьмём частоту противоположного баланса, равного $-a_i$, и вернём строку обратно.

Асимптотика: $O(\sum |s_i| + n)$ по времени и $O(n)$ по памяти.

</details>

<details>
<summary>Решение на C++</summary>

```cpp
// Для каждой строки посчитаем целое число: разницу между количеством букв "g" и "b".
// Если в строке одинаковое количество букв "g" и "b", то эта разница будет равна 0.
// Если в текущей строке разница равна d[i], то мы должны выбрать такие j, что верно
// d[i] + d[j] == 0 => d[i] = -d[j]. Для каждой разности посчитаем количество раз,
// которое она встречается, в словарь. Тогда сможем быстро считать количество строк
// с заданной разницей букв "g" и "b".
#include <bits/stdc++.h>
using namespace std;
void solve() {
    int n; cin >> n;
    vector<int> a(n);
    map<int, int> cnt;
    for (int i = 0; i < n; i++) {
        // читаем строку и считаем разницу количеств букв:
        string s; cin >> s;
        int diff = 0;
        for (auto it : s)
            diff += (it == 'g' ? +1 : -1);
        // запоминаем и заносим в словарь:
        a[i] = diff;
        cnt[diff]++;
    }
    for (int i = 0; i < n; i++) {
        // удаляем i-й элемент из словаря:
        cnt[a[i]]--;
        // считаем количество подходящих j-х элементов:
        cout << cnt[-a[i]] << ' ';
        // возвращаем i-й элемент обратно в словарь:
        cnt[a[i]]++;
    }
    cout << '\n';
}
main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int tt; cin >> tt;
    while (tt --> 0) solve();
}
```

</details>

```python
        print(cnt.get(-a[i], 0), end=' ')
        # возвращаем i-й элемент обратно в словарь:
        cnt[a[i]] += 1
    print()

while tt > 0:
    solve()
    tt -= 1
```

## D. Автобус в Таганрог

<details>
<summary>Текстовый разбор</summary>

При посадке водитель выбирает самого раннего пассажира среди тех, кто бронировал билет или уже купил его онлайн. Только если таких ожидающих нет, он смотрит на остальных. Поэтому одной очереди недостаточно: в ней пассажир без бронирования мог бы оказаться раньше пассажира с онлайн-бронированием.

Поэтому будем хранить две очереди в порядке прихода пассажиров. В первую добавим пассажиров со статусами `1` и `2`, во вторую – со статусом `0`. В запросе посадки сначала берём начало первой очереди, а если она пуста – начало второй. После этого по статусу пассажира проверяем, может ли он сесть, и при успешной посадке уменьшаем число свободных мест.

Асимптотика: $O(n + q)$ по времени и $O(n)$ по памяти.

</details>

<details>
<summary>Решение на C++</summary>

```cpp
// Честно обработаем все запросы. Для этого храним две очереди. В первую очередь будем
// складывать тех, кто купил онлайн или забронировал онлайн. Во вторую очередь - тех,
// кто не делал ни того, ни другого. При появлении нового пассажира запоминаем его деньги
// и добавляем его в конец нужной очереди. При посадке пассажира водитель сначала смотрит
// на первую очередь, вынимая элемент из её начала. Если она оказалась пустой, то смотрит
// на вторую очередь.
#include <bits/stdc++.h>
#include <cassert>
using namespace std;
void solve() {
    // читаем данные:
    int n, q, k, m;
    cin >> n >> k >> m >> q;
    string s; cin >> s;
    // создаём две очереди: для тех, кто забронировал, и для остальных
    queue<int> q0, q1;
    vector<int> money(n);
    // обрабатываем запросы:
    while (q --> 0) {
        int t; cin >> t;
        if (t == 1) {
            // приходит новый пассажир
            int id, mon;
            cin >> id >> mon;
            id--;
            money[id] = mon;
            if (s[id] == '0') // не бронировал
                q1.push(id);
            else // бронировал
                q0.push(id);
        } else {
            assert(t == 2);
            if (k == 0) { // нет мест
                cout << "-1\n";
                continue;
            }
            int id = -1;
            if (q0.size()) // сначала смотрим онлайн-очередь:
                id = q0.front(), q0.pop();
            else if (q1.size()) // теперь смотрим оффлайн-очередь:
                id = q1.front(), q1.pop();
            else {
                // нет пассажиров
                cout << "-1\n";
                continue;
            }
            if (s[id] == '2') { // уже куплен онлайн
                cout << (id+1) << '\n';
                k--;
            } else if (s[id] == '1') {
                // проверяем его деньги:
                if (m / 4 * 3 <= money[id]) {
                    cout << (id+1) << '\n';
                    k--;
                } else {
                    cout << "-1\n";
                }
            } else {
                assert(s[id] == '0');
                // проверяем его деньги:
                if (m <= money[id]) {
                    cout << (id+1) << '\n';
                    k--;
                } else {
                    cout << "-1\n";
                }
            }
        }
    }
}
main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int tt; cin >> tt;
    while (tt --> 0) solve();
}
```

</details>

<summary>Решение на Python3</summary>

```python

# складывать тех, кто купил онлайн или забронировал онлайн. Во вторую очередь - тех,
# кто не делал ни того, ни другого. При появлении нового пассажира запоминаем его деньги
# и добавляем его в конец нужной очереди. При посадке пассажира водитель сначала смотрит

# на вторую очередь.
from collections import deque


def solve():
    # читаем данные:
    n, k, m, q = map(int, input().split())
    s = input()
    # создаём две очереди: для тех, кто забронировал, и для остальных
    q0 = deque()
    q1 = deque()
    money = [0] * n
    # обрабатываем запросы:
    while q > 0:
        query = list(map(int, input().split()))
        t = query[0]
        if t == 1:
            # приходит новый пассажир
            _, id, mon = query
            id -= 1
            money[id] = mon
            if s[id] == '0':  # не бронировал
                q1.append(id)
            else:  # бронировал
                q0.append(id)
        else:
            if k == 0:  # нет мест
                print(-1)
                q -= 1
                continue
            if q0:  # сначала смотрим онлайн-очередь:
                id = q0.popleft()
            elif q1:  # теперь смотрим оффлайн-очередь:
                id = q1.popleft()
            else:
                # нет пассажиров
                print(-1)
                q -= 1
                continue
            if s[id] == '2':  # уже куплен онлайн
                print(id + 1)
                k -= 1
            elif s[id] == '1':
                # проверяем его деньги:
                if m // 4 * 3 <= money[id]:
                    print(id + 1)
                    k -= 1
                else:
                    print(-1)
            else:
                # проверяем его деньги:
                if m <= money[id]:
                    print(id + 1)
                    k -= 1
                else:
                    print(-1)
        q -= 1


tt = int(input())
while tt > 0:
    solve()
    tt -= 1
```


использован оператор запятая. Сначала `id = q0.front()` сохраняет номер первого пассажира, затем `q0.pop()` удаляет его из очереди. Эта запись эквивалентна более длинному варианту:

<summary>Разбор решения на Python3</summary>

Метод `popleft()` у `deque` одновременно возвращает первый элемент и удаляет его:

```python

```

Обычный список для этого не подходит: удаление `pop(0)` каждый раз сдвигало бы оставшиеся элементы и могло бы дать квадратичное время.

## E. Половина буквы

<details>
<summary>Текстовый разбор</summary>

Зафиксируем некоторую букву `c`. В каждом символе строки $s$ заменим `c` на $+1$, а все остальные буквы – на $-1$. На удачном отрезке половина символов равна `c`, а значит, после замены половина элементов будет равна $+1$, а вторая половина – $-1$. Поэтому сумма получившихся чисел на нём равна нулю.

Пусть мы посчитали префиксные суммы `pref` в преобразованной строке. Сумма на отрезке равна нулю тогда и только тогда, когда значения префиксной суммы до и после отрезка совпадают (`pref[r+1] = pref[l]`). Значит, нужно посчитать пары равных префиксных сумм.

Идём по строке слева направо и для каждой новой суммы прибавляем к ответу число таких же сумм, уже встреченных ранее.

Такой проход выполняем отдельно для каждой из $26$ букв: `abcdefghijklmnopqrstuvwxyz`. В варианте решения `E-1` частоты хранятся в словаре. В варианте `E-2` префиксная сумма лежит от $-n$ до $n$, поэтому её частоты можно хранить в массиве длины $2n+1$ с добавленным сдвигом $n$.

Асимптотика `E-1`: $O(26 \cdot n\log (n))$ по времени и $O(n)$ по памяти. Асимптотика `E-2`: $O(26\cdot n)$ по времени и $O(n)$ по памяти.

</details>

<summary>Решение E-1 на C++</summary>

```cpp
// Рассмотрим каждую букву отдельно. Если символ равен текущей букве, то заменим его на +1,
// а все остальные символы заменим на -1. Теперь подотрезок, на котором половина букв равна
// текущей, будет иметь половину элементов, равных +1, а вторую половину - равных -1. Таким
// образом, нам нужно посчитать количество подотрезков с суммой, равной нулю. Заранее вычис-
// лив префиксные суммы, получаем, что pref[r+1] - pref[l] == 0 => pref[r+1] = pref[l].
// Получили, что нам нужно посчитать количество пар равных элементов в массиве префиксных
// сумм. Сделаем это слева-направо, поддерживая количество каждого элемента в словаре.
// Используя map<int, int> в качестве словаря, получаем O(26 * n * log(n)).
#include <bits/stdc++.h>
using namespace std;
void solve() {
    string s;
    cin >> s;
    for (char c = 'a'; c <= 'z'; c++) {
        // создаём словарь и помещаем туда пустой префикс:
        map<int, int> cnt;
        cnt[0]++;
        // идём слева-направо, считаем префиксные суммы и считаем их количество:
        int prefSum = 0;
        int64_t answ = 0;
        for (auto it : s) {
            // обновляем префиксную сумму:
            prefSum += (it == c ? +1 : -1);
            // обновляем ответ + заносим в словарь новый элемент:
            answ += cnt[prefSum]++;
        }
        // выводим ответ:
        cout << answ << ' ';
    }
    cout << '\n';
}
main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int tt; cin >> tt;
    while (tt --> 0) solve();
}
```

<details>
<summary>Разбор решения E-2 на C++</summary>

Перед началом обхода префиксная сумма равна нулю. В коде она хранится со сдвигом `s.size()`:

```cpp
int prefSum = (int)s.size();
cnt[prefSum]++;
```

После сдвига все возможные значения лежат в диапазоне от $0$ до $2n$, поэтому ими можно индексировать `vector`. Постфиксный инкремент в строке

```cpp
answ += cnt[prefSum]++;
```

сначала прибавляет число прежних таких префиксов, а затем увеличивает их количество на единицу.

</details>

<details>
<summary>Разбор решения E-2 на Python3</summary>

В Python сдвиг префиксной суммы реализован начальным значением:

```python
pref_sum = len(s)
cnt[pref_sum] += 1
```

Поэтому индекс массива частот всегда неотрицателен. В отличие от C++, постфиксного `++` в Python нет, и обновление записано двумя действиями:

```python
answ += cnt[pref_sum]
cnt[pref_sum] += 1
```

Их порядок важен: текущий префикс нельзя учитывать как пару с самим собой.

</details>
